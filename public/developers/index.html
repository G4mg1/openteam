MiroxAI API

Build apps with Luna and Gen, our fast models, plus image generation. Chat supports streaming and returns one reply per request. Authenticate with an API key from this page.

v1 Bearer keys Free tier by OpenSurr

Chat

Non-streaming replies or streamed tokens over SSE.

Images

Generate images from a text prompt.

Web search

Ask a question that needs current facts and the reply cites sources.

Revocable keys

Create, rename, revoke or delete keys at any time.

Quick start

Create a key in API keys below, then send a chat request:

curl -X POST https://miroxai.org/v1/chat/completions \
  -H "Authorization: Bearer mxk_live_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mirox-luna-1.2",
    "message": "Hello! What can you do?"
  }'

Authentication

Send your key in the Authorization header on every request:

Authorization: Bearer mxk_live_xxxxxxxxxxxxxxxxxxxxxxxxxxxx

Key rules

  • Keys start with mxk_live_. A key shows its full value in this page, so keep a copy somewhere safe.
  • Free accounts can hold 2 active keys. Pro and Ultimate accounts can hold 10.
  • A revoked key stops working right away. Deleting a key removes it from your list.
  • Keep keys server-side. Anyone with a key can use your daily allowance.

Chat completions

POST/v1/chat/completions

Request body

FieldTypeDescription
messagestringThe user's message. Required unless you send attachments.
modelstringmirox-luna-1.2 (default) or mirox-gen-1.
historyarrayOptional earlier turns, each {"role": "user" | "assistant", "content": "..."}. Only the last 14 are used.
streambooleanSet true to receive server-sent events. Default false.
searchbooleanForce a web search for this message. Searches also run automatically for phrases like "search for …".

Response (stream: false)

{
  "reply": "Hello! I can answer questions, write and explain code, and search the web.",
  "_ms": 812,
  "provider": "pl",
  "search": null
}

When a search ran, search contains query, results (title, url, snippet) and overview.

Streaming (stream: true)

Each event is a line starting with data: followed by JSON. Read these fields:

EventMeaning
{"search": {"query": "…"}}A web search started.
{"source": {"title": "…", "url": "…"}}One search source found.
{"search_done": true, "count": 5}Search finished.
{"p": "pl"}The provider answering.
{"d": "Hel"}A piece of the reply. Append these in order.
{"img": "data:image/…"}A generated image, when the message asked for one.
{"done": true}The reply is complete.
{"error": {"message": "…"}}The request failed. Stop reading.
 
data: {"p":"pl"}
data: {"d":"Hello"}
data: {"d":" there"}
data: {"d":"!"}
data: {"done":true}
Set stream to true and read the response body with fetch or any SSE client. Ignore the data: [DONE] line if you see it.

Models

The API serves two models. Pro, Ultra and Eclipse are only available in the web app.

Model IDLabelBest for
mirox-luna-1.2LunaGeneral conversation, explanations, everyday tasks.
mirox-gen-1GenShort, direct answers and quick code snippets.

Requesting any other model with an API key returns 403.

Image generation

POST/v1/images/generations

Send a prompt and get back an image as a data URL. The image is also saved to your image history.

{
  "prompt": "A calm mountain lake at sunrise, soft colors"
}

Response

{
  "ok": true,
  "image": "data:image/png;base64,..."
}

Free accounts get 10 image generations per day. Paid plans get 200 (Pro) or 2000 (Ultimate). The daily count resets at midnight UTC.

Errors

StatusMeaning
400Missing or empty message or prompt.
401Missing, malformed, unknown or revoked API key.
403Model not available through the API.
404Unknown model ID.
429Daily limit reached for your plan.
502The upstream model failed. Retry in a moment.

Error bodies look like {"error": {"message": "…"}}.
