Quick Start

Make your first API call in under a minute:

curl -X POST https://your-domain.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mirox-luna-1.2",
    "messages": [
      {"role": "user", "content": "Hello!"}
    ]
  }'

Node.js example

const res = await fetch('https://your-domain.com/v1/chat/completions', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    model: 'mirox-luna-1.2',
    messages: [{ role: 'user', content: 'Hello!' }],
    stream: false,
  }),
});
const data = await res.json();
console.log(data.reply);

Authentication

Every request must include your API key in the Authorization header. Generate keys from Plans → API keys inside the app. 

Authorization: Bearer mxk_live_xxxxxxxxxxxxxxxxxxxxxxxx

Key rules

  • Keys are prefixed with mxk_ and hashed with SHA-256 in the database.
  • Never expose keys in client-side code — call the API from your server.
  • Free plan: max 2 keys. Pro: 5. Ultimate: 20.

Chat Completions

POST /v1/chat/completions

Request body

FieldTypeDescription
modelstringmirox-luna-1.2 or mirox-gen-1
messagesarrayArray of {role, content} objects
streambooleanEnable SSE streaming (default false)
temperaturenumber0–2, default 0.7

Example request

{
  "model": "mirox-luna-1.2",
  "messages": [
    {"role": "system", "content": "You are helpful."},
    {"role": "user", "content": "What is 2+2?"}
  ],
  "stream": false,
  "temperature": 0.7
}

Example response

{
  "ok": true,
  "reply": "2 + 2 equals 4.",
  "model": "Luna",
  "daily_used": 1,
  "daily_remaining": 49
}

Streaming

Set stream: true to receive Server-Sent Events:

data: {"d":"Hello"}
data: {"d":" there"}
data: {"d":"!"}
data: {"done":true,"model":"Luna"}

Models

Only two models are available via the public API. Others are reserved for the in-app experience.

Model IDLabelContextBest for
mirox-luna-1.2 Luna ~900 tokens Friendly conversation, general tasks
mirox-gen-1 Gen ~600 tokens Code-only output, ultra-concise

Image Generation

POST /v1/images/generations

Powered by FLUX.1-schnell on Hugging Face.

Request body

FieldTypeDescription
promptstringDescription of the image
aspect_ratiostring1:1, 16:9, 9:16, 4:3
 
{
  "prompt": "A serene mountain landscape at sunset",
  "aspect_ratio": "16:9"
}

Response

{
  "ok": true,
  "image": "https://.../generated.png"
}

Errors

StatusMeaningFix
400Invalid request bodyCheck required fields
401Missing or invalid API keyRe-generate key in Plans
403Model not allowed via APIUse Luna or Gen
429Daily limit reachedWait 24h or upgrade
502Upstream errorRetry request

Error response shape

{
  "ok": false,
  "error": "Daily message limit reached (50/day). Refills in 24 hours.",
  "limit_reached": true
}
