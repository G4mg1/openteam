Quick Start

Make your first API call in under a minute:

curl -X POST https://miroxai.org/v1/chat/completions \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mirox-luna-1.2",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'

Authentication

Every request must include your API key in the Authorization header. Generate keys from Plans → API keys inside the app.

Authorization: Bearer mxk_live_xxxxxxxxxxxxxxxxxxxxxxxx

Key rules

  • Keys are prefixed with mxk_ and hashed with SHA-256 in the database.
  • Never expose keys in client-side code — call the API from your server.
  • Free plan: max 2 keys. Pro: 5. Ultimate: 20.

Chat Completions

POST/v1/chat/completions

Request body

FieldTypeDescription
modelstringmirox-luna-1.2 or mirox-gen-1
messagesarrayArray of {role, content}
streambooleanEnable SSE streaming (default false)
temperaturenumber0–2, default 0.7

Example request

{
  "model": "mirox-luna-1.2",
  "messages": [
    {"role": "system", "content": "You are helpful."},
    {"role": "user", "content": "What is 2+2?"}
  ],
  "stream": false
}

Streaming

Set stream: true to receive Server-Sent Events:

data: {"d":"Hello"}
data: {"d":" there"}
data: {"d":"!"}
data: {"done":true,"model":"Luna"}
