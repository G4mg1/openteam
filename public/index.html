Bridge Workspace

Give Mirox direct control over your laptop. It writes files, runs commands, sends emails, checks system health, and controls your phone with KDE Connect.

  1. Click Download client (top right) → extract the ZIP.
  2. Run pip install aiohttp then python runner.py.
  3. Optional: sudo apt install kdeconnect for phone control.
  4. Click Connect in the right panel.
